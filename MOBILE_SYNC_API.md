# PosturePal Mobile-Web Synchronization API

This document describes the complete API for synchronizing data between the PosturePal web app and React Native mobile app.

## Overview

The synchronization system uses a QR code pairing mechanism similar to WhatsApp Web, followed by REST API calls and webhooks for real-time data exchange.

## Pairing Flow

### 1. Web App Generates QR Code

```typescript
// Web app calls:
POST /api/pair/generate
{
  "userId": "user_id_here"
}

// Response:
{
  "success": true,
  "qrData": "{\"code\":\"uuid\",\"userId\":\"...\",\"timestamp\":...,\"expiresAt\":\"...\",\"version\":\"1.0\"}",
  "pairingCode": "uuid-pairing-code",
  "expiresAt": "2024-11-18T22:00:00.000Z",
  "expiresIn": 300
}
```

### 2. Mobile App Scans QR Code

The mobile app scans the QR code and extracts the JSON data:

```typescript
interface QRCodeData {
  code: string;        // Pairing code
  userId: string;      // User ID
  timestamp: number;   // Generation timestamp
  expiresAt: string;   // Expiration time (ISO 8601)
  version: string;     // Protocol version
}
```

### 3. Mobile App Establishes Connection

```typescript
// Mobile app calls:
POST /api/pair/connect
{
  "pairingCode": "uuid-from-qr",
  "deviceId": "unique-device-id",  // UUID generated by app
  "deviceName": "iPhone 14 Pro",   // Device.modelName
  "deviceType": "ios",             // "ios" or "android"
  "fcmToken": "fcm-token-here"     // Optional: for push notifications
}

// Response:
{
  "success": true,
  "message": "Device paired successfully",
  "device": {
    "id": "device_id",
    "deviceId": "unique-device-id",
    "deviceName": "iPhone 14 Pro",
    "deviceType": "ios",
    "pairedAt": "2024-11-18T21:30:00.000Z"
  },
  "user": {
    "id": "user_id",
    "email": "user@example.com",
    "name": "John Doe"
  }
}
```

```typescript
interface PostureSession {
  id: string;
  startTime: string;  // ISO 8601
  endTime: string | null;
  duration: number | null;  // minutes

  goodPosturePercent: number | null;

  // Time breakdown (seconds)
  timeExcellent: number | null;
  timeGood: number | null;
  timeFair: number | null;
  timePoor: number | null;

  // Alerts
  alertsReceived: number | null;
  postureAlerts: number | null;
  breakReminders: number | null;
  correctionSpeed: number | null;  // seconds

  // Points
  pointsEarned: number | null;
  bonusPoints: number | null;

  // Analysis
  problemAreas: Record<string, number> | null;  // e.g., {"neck": 5, "shoulders": 3}
  mostCommonIssue: string | null;
  longestGoodStreak: number | null;  // seconds
  isPersonalRecord: boolean;
  recordType: string | null;

  // Environmental
  avgScreenDistance: number | null;  // cm
  lightingQuality: string | null;  // "good" | "fair" | "poor"

  // AI-generated
  aiInsights: Array<{
    type: string;
    message: string;
    severity?: string;
  }>;
  recommendations: Array<{
    type: string;
    title: string;
    description: string;
    priority: string;
  }>;

  // Timeline for graphs
  postureTimeline: Array<{
    timestamp: number;
    score: number;
  }> | null;
}
```


## Sync Strategy Recommendations

### For Mobile App

1. **Initial Sync**: On first pairing or app launch if paired
2. **Periodic Sync**: Every 5-10 minutes while app is active
3. **Incremental Sync**: Use `since` parameter to get only updated data
4. **Background Sync**: Use background fetch to sync even when app is closed
5. **Conflict Resolution**: Web app is source of truth for posture data; mobile for exercise completion

### Example React Native Implementation

```typescript
// Pairing
const pairDevice = async (qrData: string) => {
  const data = JSON.parse(qrData);

  const response = await fetch('https://api.posturepal.com/api/pair/connect', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      pairingCode: data.code,
      deviceId: await getDeviceId(),  // Store this in AsyncStorage
      deviceName: Device.modelName,
      deviceType: Platform.OS,
      fcmToken: await messaging().getToken(),
    }),
  });

  const result = await response.json();

  if (result.success) {
    // Store pairing info
    await AsyncStorage.setItem('userId', result.user.id);
    await AsyncStorage.setItem('deviceId', result.device.deviceId);
    await AsyncStorage.setItem('paired', 'true');

    // Perform initial sync
    await syncData();
  }
};

// Syncing
const syncData = async () => {
  const userId = await AsyncStorage.getItem('userId');
  const deviceId = await AsyncStorage.getItem('deviceId');
  const lastSync = await AsyncStorage.getItem('lastSync');

  const response = await fetch('https://api.posturepal.com/api/sync/data', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      userId,
      deviceId,
      since: lastSync || undefined,
    }),
  });

  const data = await response.json();

  if (data.success) {
    // Update local state/database
    await updateLocalData(data);
    await AsyncStorage.setItem('lastSync', data.timestamp);
  }
};

// Notify web of completed exercises
const notifyExerciseCompleted = async (exercises, duration, points) => {
  const userId = await AsyncStorage.getItem('userId');
  const deviceId = await AsyncStorage.getItem('deviceId');

  await fetch('https://api.posturepal.com/api/sync/webhook', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      deviceId,
      userId,
      eventType: 'exercise_completed',
      data: {
        exercises,
        duration,
        pointsEarned: points,
      },
    }),
  });
};
```

## Security Considerations

1. **QR Code Expiry**: Pairing codes expire after 5 minutes
2. **Device Verification**: All sync requests verify device is paired and active
3. **One-Time Use**: Pairing codes are invalidated after use
4. **HTTPS Only**: All API calls must use HTTPS
5. **Rate Limiting**: Implement rate limiting on sync endpoints (recommended: 60 requests/minute)

## Error Codes

| Code | Message | Description |
|------|---------|-------------|
| 400 | Bad Request | Missing required parameters |
| 403 | Forbidden | Device not paired or inactive |
| 404 | Not Found | User or resource not found |
| 409 | Conflict | QR code expired |
| 500 | Internal Server Error | Server error |

1. Generate QR code from web app
2. Scan with test mobile app (or use QR data directly)
3. Call connect endpoint
4. Verify pairing in device list
5. Perform sync and verify data
6. Complete exercise on mobile
7. Call webhook and verify in web dashboard
